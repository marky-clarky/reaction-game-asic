## How it works

Press start and the game waits a random delay, generated by an LFSR (a small pseudo-random number generator). Then the GO LED lights up and a counter starts. When you press the react button, the counter stops and your reaction time is shown on the output pins. Pressing early counts as cheating, and the FAIL LED lights up.

## How to test

Connect one button to the start input and another to the react input, and LEDs to the outputs. Press start, wait for the GO LED, then press react as fast as you can and read your score from the score LEDs.

## External hardware

Two push buttons and LEDs for the GO, FAIL, and score outputs.
